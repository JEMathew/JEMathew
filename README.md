# Jincen E Mathew

## Flagship project — MoveBooks AI

**Accounting migration with explainable AI and human control.** MoveBooks AI guides a synthetic
five-stage journey from readiness and mapping review to reconciliation and Verified First Productive Use.
A genuine Gemini Advisor explains uncertainty; an independent Reviewer challenges recommendations.
Humans retain approval authority, and deterministic financial checks remain authoritative.

This **non-commercial, synthetic-data-only MVP** is for approved hackathon judges and interview
panelists. All four agreed functional P0s passed acceptance. The owner visually verified saved
production Advisor explanations, Reviewer QUESTION assessment, grounding and uncertainty without
starting another analysis. The linked evidence distinguishes that acceptance from earlier server checks.
